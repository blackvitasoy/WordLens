# WordLens · 词典式英语理解工具

像剑桥词典一样理解英语：**词性 + 英美音标（可发音）+ 中文释义 + 双语例句 + 词形变化 + 派生词 + 同义词 + 常见搭配**。支持单词与长句，**全局快捷键唤起浮窗**。

## 快速开始（推荐：快捷键浮窗）

1. 双击 `启动热键翻译.bat`（无黑窗，常驻托盘）
2. 按 **Ctrl+Shift+D** 唤起翻译浮窗，再按一次收起
   - 如果 Ctrl+Shift+D 被占用，程序会自动尝试 Ctrl+Alt+D / Ctrl+Shift+K / Ctrl+Alt+K 等组合，并把实际生效的热键显示在**托盘图标提示**上（鼠标悬停托盘图标可见）
3. 在浮窗里输入单词或句子，回车即译
4. 退出：托盘图标右键 →「退出 WordLens」，或双击 `停止热键翻译.bat`

> 托盘图标双击 = 唤起/收起浮窗。右键菜单还有「打开完整词典页面」「重启后端服务」。

## 传统方式（浏览器页面）

双击 `启动WordLens.bat`，浏览器打开 `http://localhost:7788/`，输入即查。

## 能翻译什么

- **单词**：`artificial`、`meticulous`、`break down` → 完整词典卡片（音标/词性/释义/例句/词族），点 ▶ 发音
- **句子**：`Could you please send me the report by Friday?` → 整句中译（MyMemory 引擎）
- 浮窗内 `Enter` 翻译，`Esc` 收起，「复制」按钮复制结果到剪贴板

## 文件说明

| 文件 | 用途 |
|------|------|
| `启动热键翻译.bat` | 一键启动托盘 + 热键浮窗（推荐） |
| `停止热键翻译.bat` | 关闭托盘与浮窗 |
| `hotkey.ps1` | 全局热键 + 托盘 + 浮窗控制逻辑 |
| `hotkey_native.cs` | Win32 API（热键注册、窗口枚举、显示/隐藏） |
| `启动WordLens.bat` | 传统方式启动后端 |
| `server.js` | 翻译服务：有道词典 + MyMemory，含缓存与离线兜底 |
| `public/index.html` | 完整词典页面 |
| `public/popup.html` | 快捷键浮窗页面 |
| `.cache/` | 词条缓存（自动生成，1 天有效） |
| `hotkey.log` | 热键程序运行日志（排障用） |

## 数据源

- 单词：有道词典 `jsonapi`（含柯林斯 / 牛津双语例句）
- 句子：MyMemory 翻译接口
- 前端不直连外部接口，由本地 Node 服务（端口 7788）统一抓取，无 CORS 问题；查询在本地完成，不上传隐私数据

## 环境说明

- 用 Node.js v22 实现（本机 Python 被应用控制策略拦截，故未采用）
- 浮窗用本机 Chrome / Edge 的 `--app` 模式（无地址栏，像原生窗口），零额外安装
- 热键注册失败时会自动尝试备选组合；全部占用时弹窗提示

## 排障

- 按热键没反应 → 看托盘提示的实际热键；或查看 `hotkey.log`
- 浮窗没出来 → 确认 Chrome/Edge 已安装；托盘右键「重启后端服务」
- 端口 7788 被占 → 结束占用 7788 的进程后重试
