# WordLens · 桌面英语学习工作台

一个本机运行的英语学习应用：独立窗口（无浏览器地址栏）、专属图标、侧边栏工作台。覆盖**词典查词 / 中英双向翻译 / 从零学英语课程 / 每日任务 / 错题本 / 生词本 / 闪卡复习 / 查询历史 / 学习统计 / 设置**。

## 快速开始

**双击 `WordLens.bat`**（或桌面上自动生成的 `WordLens` 快捷方式）。启动器自动完成：拉起本地服务 → 常驻托盘（带图标）→ 打开独立应用窗口。首次运行会在桌面创建带专属图标的快捷方式。

## 从零学英语（v3.0 核心）

侧边栏「学习中心 / 每日任务 / 错题本」构成一套完整学习闭环，课程数据全部本地，按「音标 → 词汇 → 语法 → 情景对话 → 阅读 → 写作」循序渐进。

### 课程体系：`public/curriculum.json`

| 关卡 | 内容 | 单元数 |
|------|------|--------|
| 第 0 关 · 发音入门 | 48 个国际音标，每个都有**发音技巧**（口型、清浊、常见错误）与例词 | 6 |
| 第 1 关 · 零基础起步 | 打招呼、数字时间、be 动词、家庭、颜色物品、常用动词、疑问句型、初次见面对话、自我介绍写作、综合复习 | 10 |
| 第 2 关 · 日常场景 | 一般现在时、一天的活动、can、餐厅点餐、食物、问路、一般过去时、短文阅读 | 8 |
| 第 3 关 · 进阶表达 | 进行时/将来时、城市生活、must/should、现在完成时、电话约时间、周末旅行阅读、邮件写作 | 7 |
| 第 4 关 · 熟练运用 | 被动语态、定语从句、职场高频词、新闻阅读、观点写作、终极综合挑战 | 6 |

共 **37 课 / 100 个核心词 / 48 个音标**。课程按顺序解锁（完成上一课才能开下一课），完成得 1–3 星并记入档案。

### 统一课程播放器

六种题型，键盘全程可操作：`1–4` 选答案、`Enter` 继续/提交、`空格` 重听发音。

- **学习卡**：单词（音标 + 释义 + 例句 + 发音 + **跟读评分**）、音标（口型技巧 + 例词）、语法讲解卡
- **听、读、写**：情景对话逐句听读、分级阅读（**点任意单词即时查义** + 全文翻译）、套句型写作（对照示例自评）
- **测验**：英译中 / 中译英选择、听发音拼写、语法填空、阅读理解、听音辨音标
- **结算**：得分、星级、XP；答错的题自动进错题本；词汇课的词自动进生词本，接入 1/2/4/7/15/30 天间隔复习

### 每日任务（按日期确定性生成，每天 4 项）

| 任务 | 内容 | 奖励 |
|------|------|------|
| 学新词 | 按课程顺序取 5 个未学词，看卡 → 测验 → 听写 | +40 XP |
| 听写训练 | 从生词本到期词 + 已学词取 8 个，听音拼写 | +30 XP |
| 错题订正 | 逐题手输正确答案，**连对 2 次自动销题** | +30 XP |
| 综合小测 | 已学词随机 10 题（三种题型混合） | +40 XP |

进度、XP、等级（新芽→大师）、连续打卡天数、错题状态全部本地持久化在 `.data/learn.json`。

### 交互设计（还有什么能和我互动）

- **跟读评分**：学习卡上的麦克风按钮调用浏览器语音识别，给出与标准发音的相似度分数
- **划词即译**：阅读课文里点任何单词弹释义；工作台任意页面选中文本浮出「翻译选中文本」
- **键盘流**：`Ctrl+K` 聚焦查词；答题 `1–4` / `Enter` / `空格`；`?q=`、`?view=`、`?unit=L1U1`、`?demo=quiz` 深链可从外部程序直接唤起
- **档案可视化**：等级环、连续天数 🔥、待订正/已销题统计、课程完成度
- 深浅色主题、热键可视化捕获、剪贴板翻译、CSV 导出、托盘联动

## 词典与翻译

- **英文单词** → 完整词条（英美音标 + 发音、词性释义、双语例句、短语、同义词/派生词、词形）
- **英文句子 / 中文** → 自动判定方向整句互译
- 结果一键加入生词本、复制、发音

## 联网说明

- **词典 / 翻译 / 发音 / 跟读需要联网**：有道 `jsonapi`、MyMemory、有道语音、浏览器语音识别
- 课程内容、每日任务、错题本、生词本、统计、界面、热键、托盘**全部纯本地**，数据存 `.data/`，不上传
- 词条有 1 天缓存（`.cache/`），断网时缓存内容可用

## 传统入口（仍可用）

- `启动热键翻译.bat`：只启动托盘 + 热键浮窗；首次启动弹「设置唤起热键」向导
- `停止热键翻译.bat`：关闭托盘
- `启动WordLens.bat`：仅启动后端，浏览器打开 `http://localhost:7788/`
- 托盘右键：「打开 WordLens 工作台」「显示/收起翻译窗口」「更改唤起热键…」「重启后端服务」

## 排障

- 窗口没出来 → 确认 Chrome/Edge 已安装；看 `hotkey.log`
- 按热键没反应 → 悬停托盘图标看实际热键；或在「设置」页重设后重启托盘
- 想重新弹首次配置向导 → 删除 `hotkey_config.json` 后重启托盘
- 跟读评分不可用 → 需 Chrome/Edge 并允许麦克风权限
- 翻译失败 → 多为网络问题，稍后重试或查缓存内的历史记录
